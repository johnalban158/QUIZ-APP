Features

Everything a quiz platform needs — nothing it doesn't.

Real features from the actual app: an admin content library, a staff roster with training plans, and a no-friction taker flow.

Content library

Create, edit, and delete training modules with titles, descriptions, and reading content — then attach a PDF, DOCX, or TXT source (up to 10 MB) the quiz is based on.

Question builder

Add questions with four options, mark the single correct answer, then reorder them with one-click up/down controls. Every change is saved against the API instantly.

Publish & draft

Flip any module between Draft and Published. Takers only ever see published modules — polish privately, ship when you're ready.

Eligibility rules

Restrict a module by care specialty — Home Health Aide, Personal Care Aide, or Companion & Respite Aide — so the right people get the right training.

No-login taker flow

Takers never need an account. Enter a name, pick the assisting staff member, and start a published quiz in seconds — great for senior-assisted sessions.

Instant grading

One question at a time with a live progress bar. Results are graded the moment you submit — score, percent, pass/fail at a 70% line, plus a per-question breakdown that reveals the correct answer.

Submissions inbox

Every attempt is saved. Filter by module, sort by date or score, and drill into a full per-question review of any submission — with what they picked and what was correct.

Staff roster & training plans

Manage staff accounts with specialties, assign modules one at a time or in bulk, and watch completion percentages climb as staff pass their assigned training.

How it works

From first draft to completed training — in four steps.

  1. 1

    Build

    Admins create a module: reading content, eligibility rules, and questions with the correct answers marked.

  2. 2

    Publish & assign

    Flip the module to Published, then assign it to one staff member — or a whole roster in a single bulk assignment.

  3. 3

    Take

    Takers answer one question at a time, assisted by a named staff member. No account, no friction.

  4. 4

    Prove

    Pass at 70% and a completion is recorded to the staff member's training plan. Admins review every answer.

Get the app

Put Quiz App on every device — or run it yourself.

The frontend lives on the web, ships as an Android APK (debug build), and packs into a desktop app. The code is yours, so deploy it however you like.

View Source on GitHub

The APK is a debug build — your phone will ask you to allow Install from unknown sources. On the same Wi-Fi, tap the install page's download link and you're in.

Want it live? One command.

This page is the storefront — the app itself is a full stack (Express API + PostgreSQL). Spin it up locally and everything lights up:

npm run dev

The API serves on :4000, the app on :5173. See the repo README for the PostgreSQL setup — db:push + db:seed give you demo data in minutes.
